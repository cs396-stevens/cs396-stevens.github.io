Problems

(25 points) Biba Integrity Proof

If there is an information transfer path from object 𝑜1∈𝑂 to object 𝑜𝑛+1∈𝑂, then enforcement of Biba’s Strict Integrity Policy requires that 𝑖(𝑜𝑛+1)≤𝑖(𝑜1)∀𝑛>1.

  1. (25 points) Prove the above statement by induction.

(50 points) Bell-LaPadula Allowed Transitions

Consider a system that should implement the Bell-LaPadula Model.

Assume the following:

Security Levels: U<C<S<TS
Security Categories: {𝐴,𝐵,𝐶,𝐷}

The UNCLASSIFIED clearance is (U,∅).

Clearance Assignments:

  • s1: UNCLASSIFIED
  • s2: (C,{𝐴,𝐷})
  • s3: (S,{𝐵})
  • o1: (TS,{𝐴,𝐵})
  • o2: UNCLASSIFIED
  • o3: (S,{𝐷})
  • o4: (C,{𝐴})

Initial state of exercisable rights:

o1 o2 o3 o4
s1 -w rw -- --
s2 -- -- -w --
s3 -w -- -- r-
  1. (10 points) Is the initial state secure according to the Bell-LaPadula Model? If not, explain the violation.

  1. (40 points) Now assume the system starts in a secure state, and that the set of discretionary rights is represented with the following access control matrix:

    List the set of primitive commands (“Enter/Delete r into/from A[s, o]”) that would not cause a security breach according to Bell-LaPadula. (Exclude “Create Subject/Object”)

(25 points) Biba Inference

Consider a system with the current set of exercisable rights reperesented by the following access control matrix. (Recall that exercisable combines MAC and DAC rights).

o1 o2 o3
s1 r- rw --
s2 rw -- -w
s3 r- -- --
s4 -- -- --

Assume that this system implements integer integrity levels under the Biba Integrity Model (no categories).

  1. (10 points) Assume that this ACM is secure with respect to the Biba Model. Make no assumptions about the state of discretionary access rights. What relationships can you conclude about the relative integrity levels of the subjects and objects?

  1. (15 points) Now assume that the DAC ACM was the following:

    o1 o2 o3
    s1 rw rw -w
    s2 rw -- rw
    s3 rw -w --
    s4 r- r- r-

    List all the relationships between each subject and each object, then determine the relative integrity levels that each subject and object must belong to.
